# Mobile (Expo) — agent notes

Root rules in `../CLAUDE.md` apply. Since 2026-10-02 this folder is a normal part of the `pet-prep` monorepo (no submodule).

## Stack
Expo SDK 57 · React Native 0.86 · React 19 · TypeScript (strict) · StyleSheet only (NativeWind removed 2026-10-05) · Zustand 5 · TanStack Query 5 · laravel-echo + pusher-js · expo-video · expo-secure-store · expo-sensors · lucide-react-native · react-native-purchases (RevenueCat, M3-07) · @react-native-google-signin/google-signin + expo-apple-authentication + expo-crypto (parent social sign-in, M2-10c) · Jest (jest-expo) + RNTL.
Expo APIs change between SDKs — check https://docs.expo.dev/versions/v57.0.0/ (see AGENTS.md) before using any module. The `expo` Claude plugin is enabled in `.claude/settings.json`.

## Commands
`yarn install` · `npx expo start` · `yarn test` · `npx tsc --noEmit` · `eas build --profile development|preview|production` (`eas.json`).
The app now defaults to the **production** API (`https://api.petprep.si`, wss :443) — set `EXPO_PUBLIC_API_URL` etc. in `mobile/.env` for local work. `credentials.json` (signing) is local-only and gitignored.
Env: `EXPO_PUBLIC_API_URL`, `EXPO_PUBLIC_REVERB_APP_KEY|HOST|PORT|SCHEME`, `EXPO_PUBLIC_REVENUECAT_IOS_KEY|ANDROID_KEY`, `EXPO_PUBLIC_GOOGLE_WEB_CLIENT_ID|IOS_CLIENT_ID|IOS_URL_SCHEME` (public; in eas.json + `.env.example` — copy them into `mobile/.env` or the Google button stays hidden in a dev-client session) (see `src/config/env.ts`, names in `.env.example`). Physical device → use the Mac's LAN IP, Android emulator → `10.0.2.2`.

## Structure & conventions
- `src/api/client.ts` — the only place that calls `fetch`. Type requests/responses with `src/api/schema.ts` (generated; never hand-edit).
- Server state → TanStack Query hooks (`src/hooks/queries/…`); Zustand (`src/store/appStore.ts`) only for session token, ws status, lock state, overlay visibility.
- Screens in `src/screens/` (child) and `src/screens/parent/`; reusable UI in `src/components/`; feature modules in `src/modules/<feature>/`.
- Styling: React Native `StyleSheet` only (no `className`; guarded by `src/__tests__/noClassName.test.ts`). **CGP v2 "Grafit in meta"** (`../brand/README.md`): colours only from `@/theme` (`palette`, `light`, `dark`, `meter`, `alpha()`; `google` = Google's sign-in button colours, only in `GoogleSignInButton`; no hex outside `src/theme`, guarded by `src/__tests__/brandColours.test.ts`), radii `radius.*`. Child = dark graphite + glass (mint primary, graphite text on mint), parent/auth = fog + white cards (graphite primary, `light.mintText` for links, never raw mint text on light). Status = ok/warn/danger tokens, meters = `meter.*`. Due care button: `ActionButton due`.
- Type: import `Text` / `TextInput` from `@/components/ui/Text` (never from `react-native`) — it maps `fontWeight` to the Instrument Sans face; headings use `fontFamily: fonts.display | fonts.displayBold` + `letterSpacing: tightTracking(size)`. Fonts load in `App.tsx` (`useBrandFonts`, native splash held until then).
- Logos: `BrandMark` / `BrandLogo` from `@/components/brand/BrandLogo` (tone `light` on fog, `dark` on graphite); app icons and splash in `assets/` are copies of `../brand/app-icon/*` (iOS icon flattened, no alpha). Dark screens set light status-bar text with `useDarkStatusBar()` (not several `<StatusBar>` elements — they looped under fake timers).
- Path aliases: `@/`, `@api/`, `@components/`, `@hooks/`, `@screens/`, `@store/`, `@modules/`, `@types/`, `@utils/`.
- No `any`. No `console.log` left in committed code (use a tiny logger).
