# Breeder checklist — sources (K-ids)

Sources for `docs/research/breeder-checklist/data.json` (ROADMAP M5-R11-06). Accessed 2026-10-11 unless noted.
Tiers as in `docs/research/dog-data/sources.md`: **A** law / regulation / breed standard / federation rules / peer-reviewed /
vet association; **B** kennel-club or cat-federation guidance page, vet charity, university, veterinary laboratory; **C** secondary.
Breed health-test lists mostly cite the existing Royal Kennel Club breed pages (S-ids in `dog-data/sources.md`); only sources
that are new for this checklist get a K-id. Quotes in `data.json` are what the fetch tool returned verbatim.

## Looked for but not found (2026-10-11)
- **KZS / Slovenian breed-club breeding rules page** — kinoloska-zveza.si blocks crawlers; the "ask the breed club" item rests on FCI Art. 19 (K7).
- **British Shorthair parents' tests** — no A/B source naming tests for breeding British Shorthairs (only commercial-lab pages, tier C) → no breed-specific list.
- **Siberian parents' tests** — World Cat Congress SIB comparison lists only GCCF deafness testing of white cats; NZCF's Siberian policy screens for HCM / PKD / PK deficiency only on suspicion → no routine breed-specific list (`not_found`).
- **Cats, general parents' tests** — iCatCare and GCCF pages do not mention testing the parents; only PDSA (K13).
- **German Shepherd, Havanese** — the first fetches were blocked; retried once successfully (S97, S138).
- **Labrador, current RKC format** — royalkennelclub.com returned a server error; K16 (older page) used.
- **Puppy Contract site** (puppycontract.org.uk) — blocked; cited through BVA (K9) and PDSA (K1).
- **German Shorthaired Pointer parents' tests** — RKC breed page (older address) returned no health section; RKC Health Standard (thekennelclub.org.uk/BreedSpecificRequirements) lists the breed with no tests in either column, without a sentence to quote → `not_found`.
- **Yorkshire Terrier parents' tests** — RKC breed page (older address, dog-data S192): "At this time this breed does not have any recommended pre-breeding health screening in place" → `none_recommended` (like the Westie). PDSA (S194) names CM/SM with a BVA/KC scheme but no verbatim sentence about screening this breed was returned → not added as `other_scheme`.
- **Boston Terrier parents' tests** (2026-10-13) — RKC breed page (dog-data S255 / S256) returned the Good / Best Practice headings without tests; RKC Health Standard (dog-data S263) lists the breed with no tests → `not_found`. The Respiratory Function Grading scheme is only planned for the breed (dog-data S261).
- **Newfoundland parents' tests** (2026-10-20) — RKC Breeds A–Z page and DNA testing page returned fetch errors → the Kennel Club BHCP 2018 (K29) used instead (Assured Breeder requirements).
- **Dalmatian parents' tests** (2026-10-21) — RKC breed page (dog-data S429) returned the Best Practice heading without tests; the AKC national breed club recommendations (K28) give hip evaluation and BAER testing (other_scheme). No A/B source for a urate (HUU) DNA test was fetched → not listed.
- **Australian Cattle Dog parents' tests** (2026-10-21) — RKC breed page (older address, dog-data S437) listed the Priority and Important tests; no new K-source needed.
