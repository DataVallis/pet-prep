# Sources — cat care data for realism (M5-R06)

All sources accessed **2026-10-08** by Claude (branch `docs/M5-R06-cat-spec`) for
[`docs/product/CAT_SPEC.md`](../../product/CAT_SPEC.md). IDs use the prefix **C** so they never
collide with the dog sources (S1–S47 in `docs/research/dog-data/sources.md`).

**How quotes were captured:** same as the dog research. Pages were read through a web-fetch tool
that returns the requested passages, and the quotes below are the passages it returned. Before any
value goes into `breed_stage_params` (a `cat-data/data.json` + seeder, after David approves
CAT_SPEC), a human should open the URL and spot-check the quote. Check C1, C14, C16 and C17 first,
because the game rules rely on them most.

"Tier" uses the same scale as the dog sources:
**A** breed standard / peer-reviewed paper / veterinary association guideline ·
**B** veterinary hospital, university or national welfare charity advice page ·
**C** secondary summary (press article, breed portal) — use only together with A/B.

## Gaps (nothing reputable found, so marked **(D)** / UNSOURCED in CAT_SPEC)
- **Play minutes as a hard rule:** C10 is the only numeric source (a vet-technician article, reviewed by a DVM). The guidelines (C8, C22) say only that play is a need.
- **Hunger / thirst decay per hour, the game's 0–100 % scale:** these are game abstractions, as they are for dogs.
- **How long a dirty litter tray is "too long"** before the cat soils elsewhere: sources give only scooping frequency (once or twice daily, C5–C7).
- **Kitten scratching or "zoomies" frequency** and any effect of missed play on the next day: not found.
- **Appearance frequencies of domestic (random-bred) cats** (colour or pattern shares): not found. As with the mutt, any weights would be a draft (`verified: false`).
- **British Shorthair:** only registry numbers (C19) and lifespan (C14, "British" group) were collected. A breed standard was not read, because the breed is not proposed for v1.
